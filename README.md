# reprise

Lunatic Rave 2 (LR2) のプレイ感の再現を目指す、Rust製のクロスプラットフォームBMSプレイヤー（開発初期）。

> **非公式プロジェクトです。** lavalse 氏および LR2 とは無関係です。LR2 本体・スキン・フォント・効果音などの素材は一切含みません。詳細は [NOTICE.md](NOTICE.md)。

## 構成
| ディレクトリ | 内容 |
|---|---|
| `chart-formats/` | 譜面記法の汎用ライブラリ（reprise-chart-*） |
| `skin-formats/` | スキン記法の汎用ライブラリ（reprise-skin-*） |
| `game/` | プレイヤー本体（DDD / クリーンアーキテクチャ） |

設計は [ARCHITECTURE.md](ARCHITECTURE.md)。

## ビルドと実行
```sh
cd game && cargo run -p reprise --release -- [--songs path/to/BMS...] [path/to/chart.bms] [--gauge groove|easy|hard|death|pattack|gattack] [--skin path/to/play.csv] [--select-skin path/to/select.csv] [--skin-root path/to/LR2] [--hs 100] [--hsfix off|max|min|avg|const|main] [--cover 0..100] [--offset ms] [--auto] [--data path/to/folder]
```
`--songs` に譜面のフォルダ（何個でも）を渡すと選曲画面から始まります。起動のたびにフォルダの中を読み直します。フォルダを開くと、その中の曲フォルダの譜面が並びます（曲フォルダが無ければ中のフォルダが並びます。LR2 と同じ）。皿（左 Shift = 上・左 Ctrl = 下）か ↑↓ で選び、鍵盤 1/3/5/7・Enter で決定（→ はフォルダを開く）、鍵盤 6 でオートプレイ、鍵盤 2・← で戻り、最初の一覧で Esc なら終了します（皿・鍵盤は LR2 と同じく 1P・2P のどちらの割り当てでも効きます）。プレイ中に Esc で選曲に戻ります。譜面ファイルを直接渡すとその譜面のプレイだけをして、Esc で終了します（リザルト画面を出したときはそれを閉じたら終了）。

譜面の一覧は LR2 と同じく鍵盤数と難易度で絞り込み、並べ替えます（既定は 5 鍵と 7 鍵だけ・すべての難易度・ディレクトリ順）。曲を選んでいるときに SELECT（既定は W）か → を押すと、難易度の絞り込みをその曲の次の難易度に替えます（上が無ければ、すべて ⇔ いちばん低い難易度）。START（既定は Q）を押している間はパネル 1 が開き、鍵盤 1 で鍵盤数の絞り込み（すべて・SINGLE・7 鍵・5 鍵・DOUBLE・14 鍵・10 鍵・9 鍵）を替えます。選曲スキンの BUTTON 10（難易度）・11（鍵盤数）・12（並べ替え: ディレクトリ・レベル・題名・クリア・スコア）を押すとそれぞれ次へ替わります。該当する譜面が無ければ LR2 と同じく次の鍵盤数・難易度に進みます。選んだものは `config.json` の `select_sort`・`select_key`・`select_difficulty` に保存します。絞り込みの名前（選曲スキンの文字列 60..62）は LR2 と同じく LR2 本体の `LR2files/Config/optionstr.csv`（`--skin-root` の下）から読みます。

曲を選んで 0.5 秒たつと、LR2 と同じくその譜面を頭からオートプレイで鳴らします（プレビュー音。`#PREVIEW` は LR2 に無いので使いません。1 回鳴らしたら繰り返さず、選ぶ曲を替えると止まります）。鳴らさないときは `config.json` の `preview` を `false` にします。

`--select-skin` に LR2 の選曲スキン（.lr2skin / .csv。種別 5）を渡すと選曲画面をそれで描き、無ければ（読めなければ）文字の一覧で描きます。スキンで描くときは LR2 と同じく、一覧は動くアニメーションで流れ（押して 300ms・押し続けて 70ms・ホイールで 200ms）、マウスのホイールで一覧を動かせ、マウスでバーを押すとそのバーを選び（`#BAR_AVAILABLE` の外のバーなら一覧が動き）、選んでいるバーを押すと決定します。BUTTON は 10..12（絞り込み・並べ替え）・13（キー設定）・15（プレイ）・16（オートプレイ）が効き、14（スキン選択）は今はクリックしても何もしません。ほかのボタン（パネルの中のオプションなど）も対応する機能が無いので何もしません。

設定は `--data` のフォルダの `config.json` に保存し、次からは引数無しで起動できます（起動引数で渡した `--songs`・`--skin`・`--select-skin`・`--skin-root`・`--gauge`・`--hs`・`--hsfix`・`--cover`・`--offset` も保存します）。選曲スキンは `config.json` の `select_skin`（パス）でも指定できます。ゲームパッドの軸は ±0.9 でボタンとして読み、`analog_scratch_ms` に数値（ms）を入れると皿に割り当てた軸を回した向きで読むアナログ皿になります（beatoraja と同じ方式。LR2 には無い）。

キー設定は LR2 と同じく、選曲スキンの BUTTON 13 を押してキー設定画面に入ります。画面は `config.json` の `keyconfig_skin`（パス。起動引数はありません）に書いた LR2 のキー設定スキン（.lr2skin / .csv。種別 8）で描き、キー設定スキンが無ければ（読めなければ）BUTTON 13 を押しても何もしません（LR2 にも代わりの画面はありません）。画面ではスキンのボタンで割り当てるキー（BUTTON 101..107 鍵盤・110/111 皿・112 START・113 SELECT・121..127/130..133 は 2P、140 で順に切り替え）と位置（150..157）を選び、キーボードのキーかゲームパッドのボタン・軸（±0.9 でボタンとして読む）を押すとその位置に割り当てます。位置は選んだままなので、押すたびに置き換わります。Delete で外し、F1 で既定の割り当てに戻し、F2 ですべて外します（F2 だけでは保存しません）。Esc か右クリックで、スキンの `#FADEOUT` の後に選曲に戻ります。割り当ては変えるたびに `config.json` の `keys` に保存します（直接書き換えてもかまいません。配列の順が位置で、空きは null、2P は名前に `p2_` を付けます）。割り当てた入力の名前は LR2 と同じ名前（LSHIFT・Z など。ゲームパッドは reprise の名前）で出ます。割り当ては 7 鍵のものだけで、9 鍵・5 鍵への切り替え（BUTTON 141..143）は効きません。2P の割り当ては LR2 と同じく、選曲・キー設定・リザルトでは 2P の操作として（2P の鍵盤のタイマー 110..117/130..137 も動きます）、プレイでは 1P の割り当てとまとめて 1P の操作として読みます。

7 鍵（5 鍵）のシングルプレイの画面です。`--skin` に LR2 のプレイスキン（.lr2skin / .csv）を渡すとそれで描き、無ければ四角形だけで描きます。`--skin-root` はスキン中のパスの基準（LR2 本体のフォルダ。既定は今のフォルダ）。キーの既定は皿 = 左 Shift / 左 Ctrl、鍵盤 1〜7 = Z S X D C F V、START = Q、SELECT = W。

2P 側で遊ぶには、LR2 と同じくプレイスキンで 2P 側を選びます（LR2 の選曲画面・パネルにはプレイ側を切り替える設定がありません）。プレイ中は 1P と 2P のどちらの割り当てでも遊べ、スキンの最上位のファイルに `#FLIPSIDE` があればスキンの 2P 側の部品（ノーツ・ゲージ・判定・皿・押下のタイマーなど）で描きます（皿は右）。プレイ側をスキン設定（`#CUSTOMOPTION`）で選ぶスキンは、`config.json` の `skin_custom` に `{"スキンのパス": {"項目名": "選んだ名前"}}`（例: `{"LR2files/Theme/x/play.csv": {"PLAY SIDE": "2P"}}`）と書いて選びます。LR2 のスキン選択画面（BUTTON 14）に当たる画面はまだ無いので、スキン設定はここに書きます（書いていない項目は先頭の選択肢）。

プレイオプション（スキンで描くときに効きます）: `--hs` はハイスピード ×100（LR2 の既定 100）、`--hsfix` は HS-FIX、`--cover` はレーンカバー（量 0〜100）、`--offset` は判定タイミング（ms。ノーツの見た目をずらす）、`--auto` はオートプレイ。プレイ中は START か SELECT を押しながら 鍵盤 1/3/5 でハイスピード −0.1・2/4 で +0.1、6/7 でレーンカバーの上げ下げ（レーンカバーが無ければハイスピード）、START か SELECT の 2 度押しでレーンカバーの表示を切り替え、マウスホイールでレーンカバーを動かせます。

遊び終えると記録を `--data` のフォルダ（既定は今のフォルダの `reprise-data`）の `score.db` に LR2 と同じ規則で保存し、結果に保存前後の記録を出します（オートプレイと PG・GR・GD が 1 つも無いプレイは保存せず、HS-FIX CONSTANT はランプを EASY までにして回数だけ保存）。

リザルト画面は `config.json` の `result_skin`（パス。起動引数はありません）に書いた LR2 のリザルトスキン（.lr2skin / .csv。種別 7）で描きます。リザルトスキンが無ければ（読めなければ）、またプレイスキン無しで遊んだときは、これまでどおり結果を文字で出します。LR2 と同じく、プレイの場面が閉じたら、オートプレイと PG・GR・GD が 1 つも無いプレイは選曲に戻り、それ以外はリザルト画面に入ります。リザルトスキンがあるときのプレイ中の途中終了も LR2 と同じで、Esc・マウスの右ボタン・START と SELECT の同時押し（全ノーツを片付けた後は START か SELECT だけでも）でプレイスキンの `#FADEOUT` の後に場面を閉じ、PG・GR・GD があれば記録を保存してリザルト画面に入ります（片付いていないノーツは BP に数え、ランプは FAILED）。画面では 1P・2P の鍵盤 1〜7・Enter・Esc・マウスの左右ボタンの押し続けで、ゲージグラフを伸ばし終えてランクを出す → （`#STARTINPUT` の第 2 引数を過ぎたら）記録更新を出す → （第 3 引数を過ぎたら）`#FADEOUT` の後に閉じる、と進みます（記録を保存していなければ記録更新は飛ばします）。閉じるときに白鍵（1/3/5/7）と黒鍵（2/4/6）を押し続けていれば同じ譜面を同じ配置（同じ `#RANDOM` の選び方）でもう一度遊び、それ以外は選曲に戻ります（譜面を直接渡して起動したなら終了）。

スキン描画は画像・数字・ゲージ・判定とコンボ・ノーツ（LN・地雷）・小節線・BARGRAPH・SLIDER・皿の回転・合成モード（加算・減算・乗算など）・フィルタ・場面の時間（`#STARTINPUT`・`#FADEOUT` など）・文字列（画像フォント `.lr2font` と OS のフォント）・BGA（画像。1 層目・2 層目・POOR 層）・リザルトのゲージグラフ（GAUGECHART_1P）に対応します。BGA の動画・バトルと DP・EFFECT の HIDDEN/SUDDEN などは描きません（[ARCHITECTURE.md](ARCHITECTURE.md#lr2-互換の根拠)）。

### ブラウザ版
`bash tools/web-build.sh` で `web/pkg/` に wasm を作り、`web/` を静的に配信して開きます（例: `python3 -m http.server -d web 8000`）。ページで譜面のフォルダ（と、使うなら LR2 本体のフォルダ）を選ぶと、そのファイルをページの中だけで読んで遊べます（選曲画面は使わず、ページで譜面を選びます）。ネイティブ版との違い: 画面の更新に合わせてしかフレームが回らない（判定の細かさは約 1 フレーム）、記録と設定は保存しない（キーは既定の割り当て。リザルトスキンも使えないので結果は文字で出す）、OS のフォントは使えず、フォント指定の文字は内蔵の英数字フォントで出す（日本語は表示できない。LR2FONT の画像フォントは使える）、音の遅延が大きいことがある。

Linux では Bevy のために `libasound2-dev libudev-dev libwayland-dev libxkbcommon-dev libfontconfig-dev` が必要です。

各 workspace で `cargo test`。CI は Linux / Windows / macOS でのテストと lint だけを行います。他アーキテクチャ向けのクロスビルドは手元で `bash tools/cross-build.sh <target>` を実行します（準備はスクリプト冒頭に記載）。`v*` タグで6ターゲットのバイナリを Release に添付します。

テストは rstest で「仕様ルール 1 つ = テスト関数 1 つ」に揃えています（[ARCHITECTURE.md](ARCHITECTURE.md#テスト方針)）。対応は `python3 tools/check_rules.py` で検査できます。

LR2互換乱数を OpenLR2 の対応表と全件照合する場合（任意）:
```sh
cd game && OPENLR2_SEEDMAP7K=/path/to/Unrandomizer_SeedMap7K.h cargo test -p domain -- --ignored
```
